Supported versions

ConsensFlow works through the coding agents you already use. This page says which version of each it works with on Mac and Windows, the newest version it has been tested on, what is known to go wrong, and the newer versions it has not been tested on yet.

How to read this page
Oldest supported
The oldest version ConsensFlow is built to work with. A mark says whether ConsensFlow checks it when it opens a window, and refuses an older one, or only states it.
Newest tested
The newest version of the agent on which ConsensFlow's own live suites last passed on that platform, with the date of the last pass. A live suite opens a real window of the agent, gives it work and reads what came back (cargo xtask live … in the source). Only the suites that passed are listed, under each agent.
Known issues
What a person would notice going wrong on the newest tested version. It leaves out failures of the test kit itself. An issue says when we are looking into it or fixing it.
Which builds
The tests ran on development builds of ConsensFlow 3.0.6 (Muse Code: of 3.0.7). Stable 3.0.5 makes the same version checks when it opens a window, and has not been run again on these versions.
